## 2. 반별 출제 변형 매뉴얼

타 반의 기출문제를 분석한 결과, 알고리즘과 기본 틀은 동일하며 **합격 기준 점수(Threshold)**만 다르게 부여되었습니다.

| 반 | 합격 조건식 | 불합격 조건식 | 비고 |
| :--- | :--- | :--- | :--- |
| **3-5반** | `score >= 60` | `score < 60` (또는 `else`) | 기본 60점 기준선 |
| **3-7반** | `score >= 80` | `score < 80` (또는 `else`) | 우수 80점 기준선 |
| **3-8반** | `score >= 75` | `score < 75` (또는 `else`) | 중간 75점 기준선 |
| **3-9반** | `score >= 85` | `score < 85` (또는 `else`) | 상위 85점 기준선 |
| **신규 반 제안** | `score >= 70` | `score < 70` (또는 `else`) | 70점 기준선 추천 |

> **선생님 TIP**: 시험 당일 칠판에 판정 기준 점수(예: "우리 반은 70점 이상 합격입니다")만 공지하면, 학생들이 원리를 이해하고 스스로 조건식을 수정하여 구현하게 됩니다.
