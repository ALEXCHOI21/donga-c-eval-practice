| **Step 0** | **환경 설정 및 명명 규격** | VS C 프로젝트 생성, 바탕화면, `수행평가3.c` | 환경 설정 미준수로 인한 감점 방지 |

| **LIVE** | **웹 가상 C 콘솔 시뮬레이터** | 기준 점수 / 입력 점수 실시간 테스트 | 브라우저 상에서 즉시 실행 및 동작 검증 |
