STEP 2 · 사용자 입력

변수 선언과 안전한 정수 입력 (scanf_s)

키보드로 숫자를 입력받는 핵심 함수 scanf_s의 원리와 가장 많이 실수하는 주소 연산자(&)를 완벽히 이해합니다.

⚠️ 절대 잊지 마세요! 주소 연산자 '&' (Ampersand)

scanf_s는 변수 자체가 아니라 변수가 저장된 메모리의 주소를 알아야 그 자리에 입력받은 값을 채워넣을 수 있습니다.

변수명 score
값: 80
메모리 주소: &score (0x00FF...)
← scanf_s가 찾아가는 곳!
❌ 감점 1순위 (주소 연산자 누락 → 프로그램 강제 종료)
int score = 0;
scanf_s("%d", score); // & 누락! 컴파일 에러 또는 충돌
✅ 만점 코드 (& 연산자 반드시 부착)
int score = 0;
scanf_s("%d", &score); // score의 메모리 주소를 전달!
Step 2 실습 코드 (step2_scanf_s.c) 
#include <stdio.h>

int main(void)
{
    // 1. 입력받을 점수를 담을 정수형 변수 선언 및 초기화
    int score = 0;

    // 2. 프롬프트 출력
    printf("성적 입력 하세요:");

    // 3. scanf_s로 정수(%d) 입력받아 변수 score의 주소(&score)에 저장
    scanf_s("%d", &score);

    // 4. 정상 입력 확인
    printf("입력 확인: 당신이 입력한 점수는 %d점 입니다.\n", score);

    return 0;
}

STEP 3 · 논리 연산자

관계 연산자 (Relational Operators)의 세계

C언어에서 크기를 비교할 때 컴퓨터는 어떻게 판단할까요? 참(True)은 숫자 1, 거짓(False)은 숫자 0으로 계산됩니다.

연산자 의미 C언어 표현 주의사항
>= 크거나 같다 (이상) score >= 80 ⚠️ => 형태로 쓰면 컴파일 에러!
<= 작거나 같다 (이하) score <= 60 ⚠️ =< 형태로 쓰면 에러!
> 크다 (초과) score > 80 80점을 포함하지 않음
< 작다 (미만) score < 80 80점을 포함하지 않음
== 같다 score == 100 ⚠️ 대입(=)과 비교(==) 구분 필수!
!= 같지 않다 (다르다) score != 0 느낌표가 부정(NOT)을 의미

💡 관계 연산의 결과는 '숫자 1 또는 0'

컴퓨터 내부에서 조건식 (score >= 80)은 그 자체로 계산되어, 참이면 1, 거짓이면 0이 됩니다.

Step 3 실습 코드 (step3_relational_operator.c) 
#include <stdio.h>

int main(void)
{
    int score = 85;
    int isPass = 0;

    // 85는 80 이상이므로 참(1)이 변수에 들어갑니다.
    isPass = (score >= 80);

    printf("85점은 80점 이상인가? 결과값: %d (1은 참, 0은 거짓)\n", isPass);

    score = 65;
    isPass = (score >= 80);
    printf("65점은 80점 이상인가? 결과값: %d (1은 참, 0은 거짓)\n", isPass);

    return 0;
}
STEP 4 · 조건 분기문

조건에 따른 갈림길 (if ~ else) 완벽 정복

조건식이 참(1)일 때는 합격 문구를, 거짓(0)일 때는 불합격 문구를 출력하는 양자택일 제어문입니다.

조건식: score >= 기준점수
참 (True / 1)
if { ... } 블록 실행
"합격을 축하합니다!"
거짓 (False / 0)
else { ... } 블록 실행
"불합격입니다 화이팅!!"

🚨 흔히 빠지는 함정: if 문 뒤의 세미콜론(;)

❌ 세미콜론 실수 (조건과 상관없이 무조건 실행됨)
if (score >= 80); // <-- 세미콜론을 찍으면 if문이 여기서 끝남!
{
    printf("합격을 축하합니다!\n");
}
✅ 올바른 작성 (소괄호 뒤에 세미콜론 없음)
if (score >= 80) // 세미콜론 없이 바로 중괄호 시작
{
    printf("합격을 축하합니다!\n");
}
Step 4 실습 코드 (step4_if_else.c) 
#include <stdio.h>

int main(void)
{
    int score = 0;

    printf("성적 입력 하세요:");
    scanf_s("%d", &score);

    // if-else 양자택일 조건 분기
    if (score >= 80)
    {
        // 80점 이상인 경우
        printf("합격을 축하합니다!\n");
    }
    else
    {
        // 80점 미만인 경우
        printf("불합격입니다 화이팅!!\n");
    }

    return 0;
}

#include <stdio.h>

int main(void)
{
    // [조건4] 학생 정보 및 프로그램 의도를 주석으로 기술
    // 작성자: 1학년 7반 1번 김동마
