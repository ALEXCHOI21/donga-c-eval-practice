STEP 1 · 표준 입출력 기초

화면 출력(printf)의 원리와 주석(Comment) 문법

C언어의 가장 대표적인 출력 함수인 printf()의 작동 메커니즘과, 프로그램 설명 및 가독성을 높이는 주석의 문법을 깊이 있게 학습합니다.

1. printf() 함수란?

printf는 Print Formatted의 약자로, 표준 출력 스트림(화면/콘솔)에 문자열과 서식화된 데이터를 출력하는 C 표준 라이브러리 함수입니다. 이 함수를 사용하려면 소스코드 맨 위에 표준 입출력 헤더 파일인 #include <stdio.h>를 반드시 선언해야 합니다.

2. 서식 지정자(Format Specifier)와 제어 문자

데이터의 종류에 따라 메모리에 저장된 값을 사람이 읽을 수 있는 글자 형태로 변환하여 출력합니다.

서식 문자 자료형 (Data Type) 설명 및 예시
%d 10진수 정수 (int) printf("점수: %d점\n", score);
%f 부동 소수점 실수 (float/double) printf("평균: %.2f\n", avg); (소수점 둘째자리까지)
%c 단일 문자 (char) printf("등급: %c\n", grade);
%s 문자열 (string) printf("이름: %s\n", name);

3. 이스케이프 시퀀스(Escape Sequence)와 줄바꿈 제어

역슬래시(\)로 시작하는 특수 문자로, 화면 출력 흐름을 제어합니다.

  • \n (Newline): 줄바꿈(개행). 다음 줄의 첫 번째 칸으로 커서를 이동합니다.
  • \t (Tab): 수평 탭. 일정 간격(보통 4칸 또는 8칸)만큼 커서를 띄웁니다.
  • \\, \": 역슬래시나 큰따옴표 자체를 문자열 안에 출력할 때 사용합니다.
❌ 잘못된 예: 입력 프롬프트 뒤에 줄바꿈(\n)을 넣은 경우
printf("성적 입력 하세요:\n");
scanf_s("%d", &score);

👉 커서가 다음 줄로 넘어가서 콜론(:) 옆에 입력되지 않아 양식 불일치 감점!

✅ 올바른 예: 줄바꿈 없이 콜론(:)까지만 출력한 경우
printf("성적 입력 하세요:");
scanf_s("%d", &score);

👉 커서가 콜론 바로 옆에서 깜빡이며 입력을 대기하므로 출력 양식 100% 일치!

4. 주석(Comment)의 이론과 문법

컴파일러가 기계어로 번역하지 않고 건너뛰는 개발자를 위한 설명글입니다. 프로그램의 목적, 함수 기능, 작성자 정보를 명시합니다.

C언어 2가지 주석 문법 
// 1. 단일 행 주석 (Single-line Comment): 슬래시 2개로 시작하며 줄 끝까지 주석 처리됨

/*
 * 2. 다중 행 주석 (Multi-line Block Comment):
 *    슬래시-별표로 시작하여 별표-슬래시로 닫힐 때까지 여러 줄을 주석 처리함.
 *    작성자: 1학년 1반 1번 홍길동
 *    기능: 3회차 수행평가 점수 판정 프로그램
 */

💡 컴파일러 동작 원리: C 컴파일러는 전처리(Preprocessing) 및 어휘 분석 단계에서 모든 주석을 공백(White space)으로 치환합니다. 따라서 주석을 아무리 길게 써도 최종 실행 파일의 용량이나 속도에 전혀 영향을 주지 않습니다.

Step 1 핵심 실습 코드 
#include <stdio.h>

int main(void)
{
    // [작성자 정보 주석]
    /*
     * 학번: 10101  이름: 홍길동
     * 과제: C언어 3회차 수행평가 실습
     */

    // 줄바꿈(\n) 없이 입력 유도 프롬프트 출력
    printf("성적 입력 하세요:");

    return 0;
}
STEP 2 · 변수 & 사용자 입력

변수 선언(int)과 안전한 입력(scanf_s) 및 주소 연산자(&)의 원리

키보드로 값을 입력받아 메모리에 저장하는 scanf_s() 함수의 내부 원리와, C언어에서 가장 중요한 개념 중 하나인 주소 연산자(&)를 완벽히 이해합니다.

1. 변수 선언(Variable Declaration)의 메모리 원리

변수는 데이터를 보관하기 위해 운영체제로부터 할당받은 메모리(RAM) 공간의 이름입니다. 

int score = 0;
  • int: 정수형(Integer) 키워드로, 메모리에 4바이트(32비트) 크기의 공간을 예약합니다. 표현 범위는 약 -21억 ~ +21억입니다.
  • score: 할당된 4바이트 메모리 공간을 부르기 위한 식별자(변수명)입니다.
  • = 0;: 변수를 선언함과 동시에 0을 넣어주는 초기화(Initialization) 과정입니다. 초기화를 생략하면 메모리에 남아있던 불특정 쓰레기값(Garbage value)이 들어가 오류를 유발할 수 있습니다.

2. scanf_s() 함수와 주소 연산자 '&' (Ampersand)의 본질

scanf_s는 키보드 버퍼(표준 입력)로부터 서식 문자(%d)에 맞춰 데이터를 해석한 후, 그 데이터를 저장할 메모리 위치를 직접 찾아가서 기록해야 합니다.

score (변수명)

변수 방 안에 들어있는 내용물(값)을 의미합니다.

&score (주소 연산자 + 변수명)

그 방이 위치한 실제 메모리 번지(Address)를 의미합니다.

변수명 score (4바이트 공간)
저장된 값: 80
메모리 시작 주소: &score (예: 0x0061FE14)
← scanf_s("%d", &score) 가 키보드에서 읽은 80을 채워 넣는 위치!
❌ 치명적 오류: 주소 연산자(&) 누락
int score = 0;
scanf_s("%d", score); // & 누락!

💥 동작 결과: score의 값인 0을 메모리 주소(0번지, NULL 포인터)로 착각하여 쓰기를 시도하다가 액세스 위반(Access Violation / Segfault) 충돌로 프로그램이 즉시 강제 종료됩니다.

✅ 정상 동작: 주소 연산자(&) 포함
int score = 0;
scanf_s("%d", &score); // score의 메모리 주소 전달!

✨ 동작 결과: &score가 가리키는 정확한 메모리 위치로 찾아가 사용자가 입력한 정수를 안전하게 저장합니다.

3. scanf vs scanf_s의 차이점

과거 C 표준인 scanf는 입력받을 메모리 크기를 검사하지 않아 메모리를 넘쳐 흘러 침범하는 버퍼 오버플로우(Buffer Overflow) 취약점이 있었습니다. Visual Studio는 C11 표준 부록의 보안 강화 버전인 scanf_s를 기본 권장하며, 정수 입력의 경우 서식 지정자와 주소를 전달하는 방식으로 안전하게 작동합니다.

Step 2 핵심 실습 코드 
#include <stdio.h>

int main(void)
{
    // 1. 점수를 저장할 정수형 변수 선언 및 0으로 초기화
    int score = 0;

    // 2. 줄바꿈 없이 입력 안내 프롬프트 출력
    printf("성적 입력 하세요:");

    // 3. scanf_s로 정수(%d)를 입력받아 변수 score의 주소(&score)에 저장
    scanf_s("%d", &score);

    // 4. 입력된 값 출력 확인
    printf("입력 확인: %d점을 성공적으로 입력받았습니다.\n", score);

    return 0;
}

STEP 3 · 논리 & 조건 연산

관계 연산자(Relational Operators)와 참(1)과 거짓(0)의 계산 원리

컴퓨터가 두 값의 대소를 비교하는 관계 연산자의 6가지 종류와, 조건식이 실제로 계산되어 반환하는 수치적 참(1)과 거짓(0)의 메커니즘을 학습합니다.

1. C언어의 참(True)과 거짓(False) 평가 원리

순수 C언어에서 조건식(Comparison Expression)은 특별한 불리언 객체가 아닌 정수(Integer) 값으로 직접 계산됩니다.

  • 참 (True): 조건식이 만족되면 컴퓨터는 정확히 정수 1을 결과값으로 산출합니다. (조건식 평가 시에는 0이 아닌 모든 숫자도 참으로 간주됨)
  • 거짓 (False): 조건식이 만족되지 않으면 정확히 정수 0을 결과값으로 산출합니다.
관계 연산자 수학적 의미 C언어 표현식 평가 결과 및 주의사항
>= 크거나 같다 (이상) score >= 80 80점을 포함함. (80 이상이면 참 1, 미만이면 거짓 0)
⚠️ 주의: =>로 쓰면 문법 에러! 반드시 부등호(>)가 앞입니다.
<= 작거나 같다 (이하) score <= 60 60점을 포함함. ⚠️ =<는 문법 에러!
> 크다 (초과) score > 80 80점을 포함하지 않음 (81점부터 참).
< 작다 (미만) score < 80 80점을 포함하지 않음 (79점 이하만 참).
== 서로 같다 score == 100 ⚠️ 초특급 주의: 대입(=)은 값을 넣는 것이고, 등호 2개(==)가 같음을 비교하는 연산자입니다!
!= 서로 같지 않다 (다르다) score != 0 느낌표(!)는 부정(NOT)을 의미합니다.

2. >= (이상) vs > (초과)의 결정적 차이

수행평가 채점 기준이 "80점 이상"일 때, 어떤 학생이 80점을 입력했다고 가정해 봅시다:

  • score >= 80 : 80 >= 80 → 참(1) → 합격 처리! (올바른 작성)
  • score > 80 : 80 > 80 → 거짓(0) → 80점인데 불합격 처리되는 심각한 오류 발생!
Step 3 핵심 실습 코드 (조건식의 1과 0 계산 확인) 
#include <stdio.h>

int main(void)
{
    int score = 85;
    int result = 0;

    // 85는 80 이상이므로 조건식 (score >= 80)은 참(1)으로 계산됩니다.
    result = (score >= 80);
    printf("85 >= 80 조건식 계산 결과: %d (1=참, 0=거짓)\n", result);

    score = 65;
    // 65는 80 이상이 아니므로 조건식은 거짓(0)으로 계산됩니다.
    result = (score >= 80);
    printf("65 >= 80 조건식 계산 결과: %d (1=참, 0=거짓)\n", result);

    return 0;
}
STEP 4 · 조건 분기문

조건 분기문 (if ~ else)의 실행 흐름과 문법 규칙

프로그램이 주어진 조건식의 결과(참 또는 거짓)에 따라 서로 다른 명령을 실행하도록 길을 나누는 양자택일 제어문 if ~ else의 완벽한 문법과 동작 흐름을 학습합니다.

1. if ~ else 문법 구조와 실행 원리

if (조건식)
{
    // 조건식이 참(1)일 때만 실행되는 문장들
}
else
{
    // 조건식이 거짓(0)일 때만 실행되는 문장들
}

CPU는 먼저 if의 소괄호 안 조건식을 평가합니다. 조건식의 결과가 참(1)이면 if 중괄호 블록을 실행하고 else 블록은 건너뜁니다. 반대로 조건식의 결과가 거짓(0)이면 if 블록은 건너뛰고 else 블록을 실행합니다.

조건식 평가: score >= 기준점수
조건식이 참 (1)
if 블록 진입
printf("합격을 축하합니다!\n");
조건식이 거짓 (0)
else 블록 진입
printf("불합격입니다 화이팅!!\n");

🚨 절대 하지 말아야 할 실수: if 소괄호 뒤의 세미콜론(;)

C언어에서 세미콜론(;)은 하나의 문장이 완전히 끝났음을 알리는 마침표입니다.

❌ 세미콜론 실수 (조건과 무관하게 무조건 실행됨)
if (score >= 80); // <-- 세미콜론으로 인해 if문이 여기서 즉시 종료!
{
    printf("합격을 축하합니다!\n"); // 점수가 20점이어도 무조건 실행됨!
}

💥 if 조건식 뒤에 세미콜론을 찍으면 "조건이 참이면 아무것도 하지 마라"는 뜻이 되어버립니다. 그 뒤의 중괄호는 독립된 블록으로 인식되어 무조건 실행됩니다!

✅ 올바른 문법 (소괄호 뒤에 세미콜론 없음)
if (score >= 80) // 세미콜론 없이 바로 중괄호 블록 연결!
{
    printf("합격을 축하합니다!\n");
}
